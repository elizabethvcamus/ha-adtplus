# Security

Please do not publish ADT+ credentials, tokens, callback URLs, account numbers,
location payloads, or raw WebSocket traces.

For security issues that could expose credentials or permit unintended control
of a security system, use a private disclosure channel provided by the
repository owner rather than opening a public issue.

When providing logs, redact authentication headers, JWTs, refresh tokens,
account identifiers, addresses, and personally identifying device/location
names.
